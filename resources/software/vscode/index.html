    VS Code¶

    智官超（Loren-zzi）

    Visual Studio Code（VS Code） 是一款由微软开发的免费代码编辑器，支持 Windows、macOS 和 Linux。它体积较轻、启动速度快，可以用来编写和阅读 C、Python、Java 等多种编程语言的代码。
    VS Code 的一大特点是可以安装扩展。比如，安装 Python 扩展后，编辑器可以提供代码补全和运行辅助；安装中文语言包后，界面也可以切换为中文。它还内置终端，方便大家在同一个窗口中编写代码和运行命令。
    对于刚开始学习编程的大一新生来说，VS Code 界面简洁、资料丰富，同样是我本人非常非常喜欢的一款开发工具。需要注意的是，VS Code 本身只是一个编辑器，学习某些语言时还需要另外安装对应的编译器或运行环境。

    拥有一个舒适的开发环境是一件很幸福的事情，我很喜欢VS Code，他有很多自定义的插件，你可以把你写代码的地方装修成如何你想要的样子，会有很不错的写代码体验

    2，让写代码变得优雅、丝滑¶

    https://www.bilibili.com/video/BV1Hd4y1o7CN/?spm_id_from=333.1387.favlist.content.click&vd_source=dfc50a269d29e0f7601921f49f5e789d 跟着这个视频操作，你的vscode就能变得很好看很丝滑， https://blog.csdn.net/qq_51173321/article/details/126287293 （这个对应的是他的文字博客）

    下面是我个人的配置。想要使用的话，先在 VS Code 中按 Ctrl + Shift + P，搜索并选择“首选项：打开用户设置 (JSON)”（英文界面为 Preferences: Open User Settings (JSON)）。

    打开 settings.json 后，如果文件里已经有设置，请把下面大括号内的设置项合并到原有的大括号中，注意设置项之间用英文逗号分隔；如果有同名设置，修改已有的值即可，不要重复添加。完成后保存文件。

    {
  // 文件设置
  "files.autoSave": "afterDelay",
  "files.autoGuessEncoding": true,
  "files.insertFinalNewline": true,
  "files.trimTrailingWhitespace": true,

  // 滚动和光标动画
  "workbench.list.smoothScrolling": true,
  "editor.cursorSmoothCaretAnimation": "on",
  "editor.smoothScrolling": true,
  "editor.cursorBlinking": "smooth",
  "editor.mouseWheelZoom": true,

  // 自动格式化
  "editor.formatOnPaste": true,
  "editor.formatOnType": true,
  "editor.formatOnSave": true,

  // 编辑器显示
  "editor.wordWrap": "on",
  "editor.guides.bracketPairs": true,
  "editor.guides.bracketPairsHorizontal": true,
  "editor.guides.highlightActiveBracketPair": true,
  "editor.stickyScroll.enabled": true,
  "editor.renderWhitespace": "selection",
  "editor.renderLineHighlight": "all",
  "editor.minimap.maxColumn": 80,
  "editor.minimap.renderCharacters": false,

  // 代码补全
  "editor.suggest.snippetsPreventQuickSuggestions": false,
  "editor.acceptSuggestionOnEnter": "smart",
  "editor.suggestSelection": "recentlyUsed",
  "editor.quickSuggestionsDelay": 0,
  "editor.parameterHints.cycle": true,

  // 界面与文件管理
  "window.dialogStyle": "custom",
  "debug.showBreakpointsInOverviewRuler": true,
  "explorer.compactFolders": true,

  // 终端
  "terminal.integrated.cursorBlinking": true,
  "terminal.integrated.cursorStyle": "line",
  "terminal.integrated.smoothScrolling": true,
  "terminal.integrated.scrollback": 10000,

  // 主题与图标

  // Code Runner
  "code-runner.runInTerminal": true,
  "code-runner.saveAllFilesBeforeRun": true,
  "code-runner.saveFileBeforeRun": true
}

    其中主题、图标和 Code Runner 相关设置需要安装对应扩展才会生效。自动格式化也通常需要安装并配置相应语言的格式化工具
