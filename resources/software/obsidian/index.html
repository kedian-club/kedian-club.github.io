    Obsidian

    Obsidian 是一款笔记和知识管理软件，支持 Windows、macOS、Linux、Android 和 iOS。你可以用它记录课堂笔记、整理学习资料、撰写文章，也可以把不同的笔记联系起来，慢慢建立属于自己的知识库。

    Obsidian 使用 Markdown 格式保存笔记。简单来说，你写下的内容会以一个个 .md 文件保存在电脑的文件夹里，即使不用 Obsidian，也可以用其他文本编辑器（比如vscode）打开。

    和 VS Code 类似，Obsidian 也支持主题和插件。你可以根据自己的习惯调整界面、添加功能，把它变成一个适合自己学习和思考的空间。

    仓库地址： https://github.com/kedian-club/kedian-software-obsidian.git

    介绍：¶

    同你们很多人一样，我也有写笔记、写周记的习惯，我觉得这样很好，文字更具有逻辑性与持久性

    后来上了大学学习到的技术知识越来越多，以往的备忘录和Word就只能简单写写碎碎念，大段的代码根本存不了，经好友推荐让我发现了非常非常好用的笔记软件——obsidian，一个本地的非常轻量化的软件，本地意味着它绝对的安全、也比很多软件打开速度快（比如飞书就超级笨重，每次打开都要很久）

    我本人也非常非常喜欢使用Obsidian，就像这个网站的md文章编写都是这里完成，Obsidian有一个管理仓库（文件夹）的概念，这个也和vscode很相似；同样他也能使用很多很多插件（可能有一些插件下载需要点magic）可以加入用来修饰你的工作区，它还可以看到关系图谱也很漂亮

    当然，最最重要的是Obsidian更适合放自己的技术笔记，写代码、放图片都很方便

    现在是ai时代，很多时候我们也可以让ai来整理我们的笔记，Obsidian里也有关于ai的插件可以接入gpt、claude等模型（但是很多关键性的一定要自己写！！！）

    关于使用：¶

    1，首先你可以在官网或者仓库地址下载Obsidian，
    仓库地址： https://github.com/kedian-club/kedian-software-obsidian.git

    2，下载完成之后，可以跟着视频去创建自己的第一个知识库吧 【Obsidian入门保姆级教程：20分钟轻松上手Obsidian！】 https://www.bilibili.com/video/BV1Xi4y1h76C/?share_source=copy_web&vd_source=172fb8291dc4a2ef1ce47ef40f1be99d

    3，我在仓库里面也给大家准备了我的基础配置文件，可以极大提高编写体验

    好了，如果你配置到了这里，我建议你先停下一段时间先不着急继续捣鼓你的Obsidian，补药忘了多学技术、沉淀技术、多写笔记！！！

    进阶一些：¶

    多平台同步：¶

    由于obsidian是一个本地软件，导致它有唯一的一个缺点就是无法直接实现多平台同步（官方同步又需要钱，这是我们不愿意见到的）

    注：以下是我好朋友使用的方法，我本人没有验证，你们可以试试：

    方法：可以通过微软的Onedrive或者是github同步，具体实现可以自行搜搜B站

    接入AI的使用：¶

    我是用的插件是Open Claudian插件，可以接入gpt、claude等模型的api
    就能够在Obsidian内部直接使用ai，我之前一直喜欢让它画流程图很好用。

    注：但是实话我已经好久没有使用这里的AI插件，因为现在的Agent已经很厉害了，直接在codex上改也完全可以还不用再重新组织语言再讲一遍（当然如何，选择请读者自行甄别）
